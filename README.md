# Transcribe App

![Release](https://img.shields.io/github/v/release/PMCulture-pro/transcribe-app)
![License](https://img.shields.io/github/license/PMCulture-pro/transcribe-app)
![Platform](https://img.shields.io/badge/platform-macOS%20(Apple%20Silicon)-blue)

**Локальная транскрибация аудио и видео файлов на macOS с использованием AI**

Быстро и просто превращайте речь из видео и аудио записей в текст прямо на вашем Mac. Все работает локально, без интернета и без передачи данных куда-либо.

---

## Особенности

- **Быстрая работа** - оптимизировано для Apple Silicon (M1/M2/M3/M4)
- **Полностью локально** - все данные остаются на вашем компьютере
- **Простота использования** - правый клик → "Транскрибировать"
- **Поддержка видео** - автоматически извлекает аудио из .mov, .mp4, .avi и др.
- **Поддержка аудио** - работает с .mp3, .wav, .m4a и др.
- **Автоопределение языка** - Whisper сам определяет язык (~100 языков); `TRANSCRIBE_LANG=ru` фиксирует русский (надёжнее на коротких/шумных фразах)
- **Две нейросети** - опционально вторая модель [GigaAM v3](https://github.com/salute-developers/GigaAM) (Sber, одна из сильнейших для русского): каждый файл распознаётся и Whisper, и GigaAM, рядом появляются `<имя>.whisper.txt` и `<имя>.gigaam.txt` — сравнивайте и берите лучшее
- **Спикеры и таймкоды** - опционально: «[00:01:23] Спикер 2: …» — кто и когда говорил (локально, без облака)
- **Чистый текст** - результат сохраняется рядом с исходным файлом
- **Бесплатно** - открытый исходный код, никаких подписок

## Требования

- **macOS** 11.0 (Big Sur) или новее
- **Apple Silicon** (M1/M2/M3/M4)
- **~3.5 GB** свободного места на диске (+1.5 GB, если ставить вторую модель GigaAM)
- **Интернет** только для установки (после установки работает offline)

## Установка

### Быстрая установка (одна команда)

Откройте **Терминал** и выполните:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/PMCulture-pro/transcribe-app/main/scripts/install.sh)
```

### Или скачайте установщик

1. [Скачайте install.sh](https://github.com/PMCulture-pro/transcribe-app/releases/latest)
2. Откройте **Терминал**
3. Выполните:
   ```bash
   bash ~/Downloads/install.sh
   ```

### Опционально: вторая нейросеть GigaAM

Чтобы каждый файл распознавался двумя моделями (Whisper + [GigaAM v3](https://github.com/salute-developers/GigaAM) от Sber), запустите установщик с флагом:

```bash
WITH_GIGAAM=1 bash <(curl -fsSL https://raw.githubusercontent.com/PMCulture-pro/transcribe-app/main/scripts/install.sh)
```

Установщик создаст изолированное Python-окружение с PyTorch (~1 GB) и скачает модель (450 MB), а заодно — модели разметки спикеров (~35 MB, см. [«Спикеры»](#спикеры-кто-говорит)). Флаг можно добавить и поверх уже установленного приложения — Whisper-часть не трогается. Подробнее — в разделе [«Две нейросети»](#две-нейросети-whisper--gigaam).

### Что произойдет при установке?

Установщик покажет что будет скачано:

```
Что будет установлено:

  * Whisper Model (large-v3) - AI модель для транскрибации
    Размер: 3.0 GB

  * Whisper-cpp - Оптимизированный транскрибатор для Apple Silicon
    Размер: ~5 MB

  * FFmpeg - Инструмент для работы с аудио/видео
    Размер: 95 MB

  * Quick Action - Интеграция в контекстное меню Finder
    Размер: <1 MB

Общий объем загрузки: ~3.1 GB
Время установки: ~10-15 минут
```

**Примечание:** Установка может занять 10-15 минут в зависимости от скорости интернета.

## Как использовать

### Способ 1: Через контекстное меню (самый простой)

1. Найдите любой видео или аудио файл в **Finder**
2. **Правый клик** на файле
3. Выберите **Quick Actions** → **Транскрибировать**
4. Рядом с файлом сразу появится **`<имя>.InProgress.txt`** — индикатор того, что
   идёт работа. Нажмите на него **пробел** (Quick Look), чтобы увидеть время старта,
   примерную длительность и ожидаемое время завершения.
5. По окончании создаётся **`<имя>.whisper.txt`** с готовым текстом, а файл `.InProgress.txt`
   автоматически удаляется. Если установлен GigaAM, рядом появится и **`<имя>.gigaam.txt`** —
   та же запись, распознанная второй сетью.

> **Сколько ждать?** Оценка времени **самообучающаяся**: после каждого запуска
> приложение запоминает реальную скорость вашего Mac и в следующий раз показывает
> точный прогноз. Несколько выделенных файлов обрабатываются **по очереди**.

### Способ 2: Через командную строку

```bash
# Транскрибировать конкретный файл
bash "$HOME/Library/Application Support/Transcribe/bin/transcribe.sh" "путь/к/файлу.mov"
```

### Настройки (env-переменные)

Передаются перед вызовом скрипта (в командной строке) — управляют качеством и форматом вывода:

```bash
# Максимальное качество + таймкоды + читаемые абзацы (язык ru — по умолчанию)
QUALITY=max TIMESTAMPS=1 READABLE=1 \
  bash "$HOME/Library/Application Support/Transcribe/bin/transcribe.sh" "запись.mov"
```

Те же ключи можно записать в [файл настроек](#файл-настроек) — тогда они действуют и для правого клика в Finder.

| Переменная | Значения | По умолчанию | Что делает |
|------------|----------|--------------|------------|
| `ENGINE` | `auto`, `whisper`, `gigaam`, `both` | `auto` | Какими сетями распознавать. `auto` = обе, если GigaAM установлен (и язык `auto`/`ru`), иначе только Whisper. Whisper пишет `<имя>.whisper.txt`, GigaAM — `<имя>.gigaam.txt` |
| `GIGAAM_DEVICE` | `auto`, `mps`, `cpu` | `auto` | Где считать GigaAM: `auto` = GPU (Metal) с откатом на CPU при ошибке |
| `MODEL` | `large`, `turbo` | `large` | Модель Whisper. `turbo` (large-v3-turbo) ~3× быстрее при сопоставимом качестве. Нужна turbo-модель: переустановить с `WITH_TURBO=1`. Если не скачана — откат на `large` |
| `TRANSCRIBE_LANG` | `auto`, `ru`, `en`, … | `auto` | Язык распознавания Whisper. `auto` — автоопределение (подходит и для не-русских, и для разноязычных записей); фиксированный `ru` убирает ложные детекты на коротких/шумных фразах. GigaAM всегда русский |
| `QUALITY` | `fast`, `balanced`, `max` | `balanced` | Точность ↔ скорость Whisper. `max` точнее, но в 2–4× медленнее |
| `TIMESTAMPS` | `0`, `1` | `0` | Таймкоды `[ЧЧ:ММ:СС]` прямо в тексте расшифровки |
| `READABLE` | `0`, `1` | `0` | Разбивка на абзацы по паузам + перенос длинных строк |
| `VAD` | `auto`, `1`, `0` | `auto` | Whisper: отсекает выдуманный текст в тишине/паузах. `auto` — включён, если VAD-модель скачана установщиком; `1` — принудительно; `0` — выключить. GigaAM режет речь своим VAD всегда |
| `STRIP_FILLERS` | `0`, `1` | `0` | Убрать междометия-растяжки «э-э», «а-а», «м-м» из расшифровки (GigaAM пишет их дословно, Whisper — изредка). Оба движка |
| `SPEAKERS` | `0`, `auto`, `2`, `3`, … | `0` | Разметка по спикерам: «Спикер 1: …». `auto` — число спикеров определяется само; число — точное количество (надёжнее). Нужна установка с `WITH_GIGAAM=1`. См. [«Спикеры»](#спикеры-кто-говорит) |
| `WHISPER_CLEANUP` | `0`, `1` | `1` | Убрать известные галлюцинации Whisper: титры «Редактор субтитров…», «Продолжение следует», «Спасибо за просмотр» и одинаковые строки подряд (петли). Удалённые титры пишутся рядом в `<имя>.filtered.txt` для сверки. Прежнее имя выключателя `FILTER=0` тоже работает |

### Файл настроек

Правый клик в Finder не умеет передавать переменные, поэтому те же ключи можно записать в файл:

```
~/Library/Application Support/Transcribe/settings.txt
```

Он создаётся установщиком (или при первом запуске) со всеми ключами, закомментированными `#`, и подсказками. Откройте его в TextEdit, уберите `#` перед нужной строкой и поставьте значение, например:

```
STRIP_FILLERS=1
TIMESTAMPS=1
MODEL=turbo
```

Формат — `КЛЮЧ=значение`, по одному на строку; кавычки, пробелы вокруг `=` и комментарии после `#` допустимы. Файл не исполняется как скрипт: читаются только известные ключи, опечатка ничего не сломает. Переменные, заданные в командной строке, важнее файла. При переустановке файл не перезаписывается.

## Формат результата

Текстовый файл содержит:

```txt
=========================================
Исходный файл: video.mov
Длительность аудио: 00:30:24
Старт транскрибации: 2026-06-02 17:25:13
Завершение транскрибации: 2026-06-02 17:28:34
Время транскрибации: 00:03:21
Модель: Whisper Large-v3 (язык: ru, качество: balanced)
=========================================

[Здесь идет полный текст транскрипции]
```

Файл второй сети `<имя>.gigaam.txt` устроен так же, только в шапке
`Модель: GigaAM v3 E2E-RNN-T (язык: ru, устройство: mps)`, а текст — с пунктуацией
и заглавными буквами от самой модели.

С `TIMESTAMPS=1` и `SPEAKERS=auto` текст выглядит так:

```txt
[00:00:00] Спикер 1: Доброе утро. Давайте начнём с отчёта по продажам за прошлый месяц.
[00:00:05] Спикер 2: Продажи выросли на 8%, но маржа немного снизилась из-за скидок.
[00:00:10] Спикер 1: Понятно. А что с новыми клиентами?
```

## Настройки (для продвинутых)

### Язык транскрибации

По умолчанию Whisper **сам определяет язык** (`TRANSCRIBE_LANG=auto`, ~100 языков). Если все записи на одном языке, его можно зафиксировать в файле настроек — фиксированный язык надёжнее автоопределения на коротких и шумных фразах:

```
TRANSCRIBE_LANG=ru     # зафиксировать русский
TRANSCRIBE_LANG=en     # или другой конкретный язык: en, es, de, …
```

GigaAM работает только с русским: при языке, отличном от `ru`/`auto`, в режиме `ENGINE=auto` он пропускается.

### Улучшить качество (медленнее, но точнее)

В файле настроек: `QUALITY=max` (beam 8 вместо 5, в 2–4 раза медленнее). Флаг `--temperature 0.0` в whisper.cpp специально **не** используется: он выключает fallback и провоцирует зацикливание.

## Две нейросети: Whisper + GigaAM

Whisper large-v3 — универсальная многоязычная модель. [GigaAM v3](https://github.com/salute-developers/GigaAM)
(Sber) — модель только для русского, обученная на большом русскоязычном корпусе; вариант
**E2E-RNN-T** сразу выдаёт текст с пунктуацией и заглавными буквами. На русской речи
с терминами, именами и «э-э» они ошибаются по-разному, поэтому две независимые расшифровки
одной записи полезнее одной: спорные места можно сверить, а обе версии — отдать LLM для сведения.

**Как работает.** Аудио извлекается один раз, затем движки идут по очереди (оба грузят GPU):
Whisper пишет `<имя>.whisper.txt`, GigaAM — `<имя>.gigaam.txt`. Оценка времени в `.InProgress.txt`
и уведомления учитывают оба движка; скорость каждого запоминается отдельно.

**Длинные записи.** GigaAM принимает фрагменты до 25 секунд, поэтому речь режется
Silero VAD по паузам на куски ≤ 22 с и распознаётся пачками — так же, как в штатном
`transcribe_longform`, но без pyannote и токена Hugging Face.

**Скорость.** GigaAM заметно легче Whisper large-v3. Замер на M4 (24 GB), запись 3 минуты:

| Движок | Время | Скорость |
|--------|-------|----------|
| Whisper large-v3 (`balanced`) | 43 с | ~4× realtime |
| GigaAM v3 E2E-RNN-T (MPS) | 6 с | ~30× realtime |
| GigaAM v3 E2E-RNN-T (CPU) | 7 с | ~28× realtime |

То есть вторая расшифровка добавляет к общему времени порядка 15%. На CPU и GPU текст
получается одинаковый, поэтому `GIGAAM_DEVICE=cpu` — безопасный запасной вариант.

**Чем отличаются тексты.** GigaAM пишет дословно, включая «э-э» и самоисправления
говорящего (`STRIP_FILLERS=1` убирает растяжки), везде ставит «ё» и сам расставляет
пунктуацию. Whisper даёт короткие фразы с точными таймкодами и аккуратными кавычками, но
иногда дописывает в конце записи титры из обучающих субтитров — их убирает
`WHISPER_CLEANUP=1` (включён по умолчанию). Фразы, разрезанные границей VAD-чанка,
раннер GigaAM склеивает сам: продолжение пишется в ту же строку со строчной буквы.

**Ограничения.**
- Только русский: при `TRANSCRIBE_LANG=en` (любом языке кроме `auto`/`ru`) в режиме `auto`
  GigaAM пропускается. Принудительно — `ENGINE=both`.
- `QUALITY`, `VAD`, `MODEL` относятся к Whisper. `TIMESTAMPS` и `READABLE` работают для обоих.
- Первый запуск после установки чуть дольше: PyTorch компилирует Metal-ядра.

**Вернуться к одному Whisper:** `ENGINE=whisper` перед вызовом скрипта (для Finder —
удалить папку `~/Library/Application Support/Transcribe/gigaam`).

**Логи** последнего запуска каждого движка: `~/Library/Application Support/Transcribe/logs/`.
В логе Whisper есть и сам распознанный текст (только последнего запуска, локально).

## Спикеры: кто говорит

`SPEAKERS=auto` (или точное число, например `SPEAKERS=3`) в файле настроек — и каждая реплика
в обеих расшифровках получает подпись «Спикер N:». Вместе с `TIMESTAMPS=1` — таймкод реплики.

**Как работает.** Перед распознаванием запись один раз размечается по голосам — теми же
моделями, что внутри `pyannote/speaker-diarization-3.1` (сегментация pyannote-3.0 +
эмбеддинги голоса WeSpeaker ResNet34-LM), но в ONNX через [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx):
без pyannote.audio, без токена Hugging Face, полностью офлайн. Модели (~35 MB) ставятся
вместе с GigaAM (`WITH_GIGAAM=1`), их SHA256 закреплены в установщике. Скорость — около
20× realtime (час записи ≈ 3 минуты).

- **GigaAM** режет речь на куски по смене спикера, поэтому каждая его реплика принадлежит
  одному человеку — это самый точный вариант.
- **Whisper** сам решает, где кончается фраза; спикер назначается по наибольшему перекрытию
  по времени. Если человек перебил собеседника посреди фразы Whisper, реплика целиком уйдёт
  тому, кто говорил дольше.

**Ограничения (честно).**
- Спикеры безымянные: «Спикер 1» — тот, кто заговорил первым. Имена по голосу не определяются.
- Наложение речи (двое говорят одновременно) размечается одним спикером.
- Похожие голоса могут слиться, а один голос в разных условиях (микрофон, эмоции) — раздвоиться.
  Лечится указанием точного числа: `SPEAKERS=2` надёжнее, чем `auto`.
- Короткие реплики («да», «угу») короче ~0.3 с могут приписаться соседнему спикеру.

**Таймкоды.** whisper.cpp выдаёт сегменты встык и «приклеивает» паузу к следующей фразе —
её таймкод получается раньше реального на длину паузы. Поэтому после Whisper начало и конец
каждой реплики выравниваются по реальной речи (Silero VAD, утилита `vad-speech-segments` из
whisper-cpp). GigaAM с таймкодами/спикерами режет речь также на паузах длиннее 1 с —
таймкод ставится на каждую реплику, а не на кусок до 22 с.

## Устранение проблем

### Пункт "Транскрибировать" не появляется в меню

1. Перезапустите Finder:
   ```bash
   killall Finder
   ```

2. Очистите кэш служб:
   ```bash
   /System/Library/CoreServices/pbs -flush
   ```

3. Если не помогло - переустановите:
   ```bash
   bash scripts/install.sh
   ```

### Транскрибация не запускается

Проверьте, установлены ли все компоненты:

```bash
# Проверить whisper-cpp
brew list whisper-cpp

# Проверить ffmpeg
which ffmpeg

# Проверить модель
ls "$HOME/Library/Application Support/Transcribe/models/ggml-large-v3.bin"
```

### Низкое качество распознавания

1. Убедитесь, что аудио четкое (нет сильных шумов)
2. `QUALITY=max` в файле настроек (см. «Настройки»)
3. Зафиксируйте язык записи в файле настроек (`TRANSCRIBE_LANG=ru`, `en`, …) — автоопределение ошибается на коротких/шумных фразах
4. Сравните с расшифровкой GigaAM (`<имя>.gigaam.txt`) — сети ошибаются по-разному

### Нет файла `.gigaam.txt` / GigaAM падает

1. Смотрите лог: `~/Library/Application Support/Transcribe/logs/last_gigaam.log`
2. Проверьте окружение:
   ```bash
   "$HOME/Library/Application Support/Transcribe/gigaam/venv/bin/python" -c "import torch, gigaam, silero_vad; print('ok')"
   ```
3. Если сломано — переустановите только GigaAM-часть (Whisper и модели не трогаются):
   ```bash
   rm -rf "$HOME/Library/Application Support/Transcribe/gigaam"
   WITH_GIGAAM=1 bash scripts/install.sh
   ```
4. Ошибки Metal/MPS — попробуйте `GIGAAM_DEVICE=cpu`.

### Ошибка "Permission denied"

```bash
# Дать права на выполнение
chmod +x "$HOME/Library/Application Support/Transcribe/bin/transcribe.sh"
```

```bash
bash "$HOME/Library/Application Support/Transcribe/bin/uninstall.sh"
```

## FAQ

### Нужен ли интернет для работы?

Интернет нужен только при установке для скачивания компонентов. После установки приложение работает полностью offline.

### Передаются ли данные куда-либо?

Нет! Все работает локально на вашем компьютере. Никакие аудио, видео или текстовые данные не отправляются в интернет.

### Работает ли на Intel Mac?

Приложение оптимизировано для Apple Silicon (M1/M2/M3/M4). Для Intel процессоров рекомендуется использовать другие решения.

### Почему установка занимает много места?

AI модель для качественного распознавания речи занимает ~3 GB. Это позволяет работать полностью offline и обеспечивает высокое качество.

### Можно ли использовать меньшую модель?

Технически да — whisper.cpp поддерживает модели `tiny`/`base`/`small`/`medium`. Но «из коробки» установщик ставит только `large-v3`: чтобы использовать другую, нужно скачать её вручную и поправить путь к модели в `transcribe.sh`. Такая конфигурация не тестировалась.

### Поддерживается ли диаризация (разделение по спикерам)?

Да, опционально: установка с `WITH_GIGAAM=1` и `SPEAKERS=auto` (или точное число спикеров) в файле настроек. Работает локально, без токенов и облака; спикеры безымянные («Спикер 1», «Спикер 2»). Подробности и ограничения — в разделе [«Спикеры»](#спикеры-кто-говорит).

### Можно ли транскрибировать несколько файлов сразу?

Да! Выделите несколько файлов в Finder, правый клик → Quick Actions → Транскрибировать. Они будут обработаны последовательно (по очереди).

### Есть ли в проекте ETL / пайплайн обработки данных?

Формального ETL-фреймворка (оркестратор, база данных, расписания) нет. По сути это однопроходный локальный пайплайн на bash:
- **Extract** — `ffmpeg` извлекает аудио из видео и приводит к WAV 16 кГц моно;
- **Transform** — `whisper-cli` (и, если установлен GigaAM, `gigaam_transcribe.py`) распознаёт речь в текст;
- **Load** — результат сохраняется в `<имя>.whisper.txt` (и `<имя>.gigaam.txt`) рядом с исходным файлом.

Весь конвейер целиком — в [`scripts/transcribe.sh`](scripts/transcribe.sh).

### Какая точность транскрибации?

Зависит от качества записи. Используется `large-v3` — самая точная модель Whisper; на чистом русском аудио типичный WER (доля ошибочных слов) ориентировочно **5–10%**, но на реальных совещаниях с шумом, эхом и наложением речи он заметно выше. Точную цифру для конкретных записей можно получить только замером: сравнить вывод с выверенным «эталонным» текстом (метрики WER/CER, например через пакет `jiwer`). Готовых замеров для этого проекта пока нет.

С опцией `WITH_GIGAAM=1` каждая запись распознаётся ещё и GigaAM v3 — по бенчмаркам авторов на русском она даёт заметно меньший WER, чем Whisper large-v3. Две независимые расшифровки рядом позволяют сверить спорные места без эталона.

### Сколько стоит использование?

Приложение полностью бесплатное и с открытым исходным кодом.

## Технические детали

### Используемые технологии

- **[Whisper](https://github.com/openai/whisper)** - AI модель от OpenAI для распознавания речи
- **[whisper.cpp](https://github.com/ggerganov/whisper.cpp)** - Оптимизированная C++ реализация с поддержкой Metal (GPU на Apple Silicon)
- **[GigaAM v3](https://github.com/salute-developers/GigaAM)** - AI модель Sber для русской речи (E2E-RNN-T с пунктуацией), опционально; работает на PyTorch через Metal (MPS)
- **[Silero VAD](https://github.com/snakers4/silero-vad)** - Детектор речи: режет длинные записи на фрагменты для GigaAM
- **[FFmpeg](https://ffmpeg.org/)** - Обработка аудио и видео
- **Automator** - Интеграция в macOS Finder

### Архитектура

```
Пользователь → Finder (правый клик)
    ↓
Automator Quick Action
    ↓
transcribe.sh (bash скрипт)
    ↓
FFmpeg (извлечение аудио, WAV 16 кГц моно)
    ↓                          ↓ (если установлен GigaAM)
whisper-cli (Metal)        gigaam_transcribe.py (PyTorch/MPS):
    ↓                        Silero VAD → чанки ≤ 22 с → GigaAM v3 E2E-RNN-T
<имя>.whisper.txt            ↓
                           <имя>.gigaam.txt
```

### Расположение файлов

```
~/Library/Application Support/Transcribe/
├── bin/
│   ├── transcribe.sh            # Скрипт транскрибации
│   ├── gigaam_transcribe.py     # Раннер GigaAM (используется при WITH_GIGAAM=1)
│   ├── diarize.py               # Разметка спикеров (SPEAKERS=auto|N)
│   └── uninstall.sh             # Скрипт удаления
├── models/
│   ├── ggml-large-v3.bin        # AI модель Whisper (3 GB)
│   ├── gigaam/                  # Веса GigaAM v3 E2E-RNN-T (450 MB), опционально
│   └── diarization/             # Модели спикеров: pyannote-3.0 + WeSpeaker (~35 MB), опционально
├── gigaam/venv/                 # Python-окружение GigaAM (PyTorch, ~1 GB), опционально
├── logs/                        # Вывод движков последнего запуска
├── settings.txt                 # Настройки: язык, качество, таймкоды, спикеры, движки (и для Finder)
├── last_speed_factor            # Выученная скорость Whisper
└── last_speed_factor_gigaam     # Выученная скорость GigaAM

~/Library/Services/
└── Транскрибировать.workflow  # Quick Action
```
