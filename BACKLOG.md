## Баги и корректность

### BUG-1 · Молчаливая перезапись чужих `.txt` · P0 · S
Результат всегда пишется в `<имя>.txt` ([`scripts/transcribe.sh:52`](scripts/transcribe.sh#L52)).
- Существующий `meeting.txt` (заметки пользователя) затирается без предупреждения.
- `meeting.mp3` и `meeting.mp4` дают один `meeting.txt` — второй убивает первый.

**Сделать:** при коллизии добавлять суффикс (`meeting (2).txt`) либо включать расширение в имя (`meeting.mp4.txt`). Не перезаписывать существующий файл без явного флага.

### BUG-2 · Видео без аудиодорожки → галлюцинации · P1 · S
[`scripts/transcribe.sh:92`](scripts/transcribe.sh#L92) проверяет только существование WAV, но не длительность/размер. Пустой звук → whisper выдаёт выдуманный текст.

**Сделать:** проверять `DUR_INT >= 1` и ненулевой размер WAV, иначе понятная ошибка.

### BUG-3 · Часть форматов не показывает пункт меню · P1 · S
Quick Action ограничен UTI `public.movie/audio/audiovisual-content/mpeg-4` ([`scripts/install.sh:700-706`](scripts/install.sh#L700)). README обещает `.mkv/.webm/.flac/.ogg`, но они под эти UTI часто не подпадают — пункт «Транскрибировать» не появляется.

**Сделать:** расширить `NSSendFileTypes` (вплоть до `public.data`/`public.item`) **или** сузить обещания в README.

## Поддерживаемость

### MNT-1 · `transcribe.sh` продублирован · P1 · M
Один скрипт лежит в [`scripts/transcribe.sh`](scripts/transcribe.sh) и внутри heredoc [`scripts/install.sh:285-482`](scripts/install.sh#L285). Два источника правды молча расходятся.

**Сделать:** установщик скачивает `transcribe.sh` из репозитория (`curl`), а не генерирует из себя. Один источник правды.

### MNT-2 · Мёртвая переменная / версия не пинится · P2 · S
[`scripts/install.sh:73`](scripts/install.sh#L73) `WHISPER_CPP_VERSION="1.8.0"` нигде не используется — brew ставит latest. Если апстрим переименует бинарник `whisper-cli`, установка сломается.

**Сделать:** либо реально пинить версию формулы, либо убрать переменную.

### MNT-3 · Нет shellcheck/CI · P2 · S
**Сделать:** GitHub Action со `shellcheck` на все скрипты — ловит целый класс баг автоматически.

### MNT-4 · Атомарная установка скриптов · P1 · S · ✅
bash читает скрипт по ходу исполнения. Если во время транскрибации из Finder (минуты) перезаписать
`bin/transcribe.sh` через `cp` на месте, запущенный экземпляр продолжит чтение со старого байтового
смещения в новом файле — падает с `syntax error near unexpected token` посреди слова, GigaAM-этап не
выполняется, индикатор `.InProgress.txt` остаётся. Воспроизведено 2026-09-16. `install_script` теперь
копирует во временный файл и делает `mv`: работающий процесс дочитывает старую копию (inode).

## Фичи (больше пользы из результата)

### FEAT-1 · Субтитры и таймкоды · P1 · S
Сейчас только сплошной `.txt` без привязки ко времени — по часовой записи не найти момент. whisper-cli умеет нативно:
- `--output-srt` / `--output-vtt` — субтитры поверх видео;
- `--output-json` — машиночитаемо для дальнейшей обработки;
- `--max-len 80 --split-on-word` — читаемые строки.

**Сделать:** рядом с `.txt` класть `.srt`. Самый высокий прирост пользы на минимуме усилий.

### FEAT-2 · Контекстный глоссарий · P1 · S
`--initial-prompt "имена, термины, аббревиатуры"` смещает распознавание к нужным словам — сильно снижает ошибки на фамилиях/жаргоне/продуктовых названиях.

**Сделать:** необязательный `glossary.txt` рядом с записью (есть — подхватывается, нет — игнор) или env-переменная.

### FEAT-3 · Читаемое форматирование · P2 · S
Сейчас стена текста.

**Сделать:** разбивка на абзацы по паузам + перенос строк.

### FEAT-4 · Авто-протокол через LLM · P2 · M
После транскрипта класть рядом `<имя>.summary.md`: краткое содержание, решения, action items, тайминги тем. Для встреч — главная польза.

**Сделать:** офлайн через локальный LLM (LM Studio уже стоит у пользователя) либо Claude API (`claude-haiku-4-5` для дешёвой суммаризации / `claude-opus-4-8` для качества). С диаризацией (FEAT-5) становится сильно полезнее: «Иван предложил…», «решение принял Пётр».

### FEAT-5 · Опциональная диаризация · P3 · L
«Кто говорил когда». Текущий конвейер сводит звук в моно ([`scripts/transcribe.sh:91`](scripts/transcribe.sh#L91)), поэтому `--diarize` whisper.cpp (только стерео) не подходит. Настоящая диаризация = [WhisperX](https://github.com/m-bain/whisperX) (pyannote + Python + PyTorch + токен Hugging Face).

**Сделать:** НЕ тащить в основной скрипт. Отдельный режим `transcribe-meeting.sh`, ставится по желанию (`install.sh --with-diarization`), включается только для совещаний. На выходе `.srt`/`.md` с метками спикеров.

**Риски качества:** перебивания/наложение речи, похожие голоса, метки безымянные (`SPEAKER_00/01`), авто-оценка числа спикеров мажет.

### FEAT-6 · Двойная расшифровка Whisper + GigaAM · P2 · M · ✅
Одна запись → две независимые расшифровки: `<имя>.txt` (Whisper) и `<имя>.gigaam.txt`
([GigaAM v3 E2E-RNN-T](https://github.com/salute-developers/GigaAM), Sber — с пунктуацией и заглавными).
Сети ошибаются по-разному, поэтому пара расшифровок полезнее одной: сверка спорных мест, сведение через LLM (FEAT-4).

**Как сделано:**
- `transcribe.sh`: `ENGINE=auto|whisper|gigaam|both` (auto = обе, если GigaAM установлен и язык auto/ru).
  Движки по очереди (оба грузят GPU), общая оценка времени, отдельные множители скорости, логи в `logs/`.
- `scripts/gigaam_transcribe.py`: раннер в venv. Штатный `transcribe_longform` требует pyannote + HF_TOKEN,
  поэтому нарезка своя — Silero VAD (веса в pip-пакете) → чанки ≤ 22 с → батчи через `forward` + `_decode`,
  как внутри `transcribe_longform`. Устройство `auto` = MPS с откатом на CPU.
- `install.sh`: `WITH_GIGAAM=1` — venv (Python 3.10–3.13, при отсутствии `brew install python@3.12`),
  `torch`, `silero-vad`, `gigaam` с GitHub по закреплённому коммиту (на PyPI устаревшая 0.1.0),
  предзагрузка весов с md5. Ошибка GigaAM не валит установку Whisper.

**Сравнение качества (3-мин клип + 10-мин лекция, без эталона, по контексту терминов):** расхождение между
сетями ~5% слов, половина — падежные окончания и имена (без прослушивания не решить). GigaAM точнее по терминам
(«неотфактурованная поставка», «списаний ретро-бонусов», «закрыть невозможно», «НСИ») и не имеет двух сбоев
Whisper: галлюцинация-титры в конце («Редактор субтитров А.Семкин…») и деградация сегмента (потеря пунктуации,
мусор «доп реквизита пас»). Whisper лучше по формату: «М7» кириллицей, кавычки, границы предложений, таймкод
на каждую фразу, междометия не пишет. Сделано по итогам: склейка фраз на границах чанков (раннер),
`STRIP_FILLERS=1`, `WHISPER_CLEANUP=1` (титры + петли) — пост-процессор в transcribe.sh.

**Замер (M4, 24 GB, клип 3 мин, 13 VAD-чанков):** Whisper large-v3 balanced — 43 с; GigaAM MPS fp32 — 5.4 с,
MPS fp16 — 5.5 с, CPU — 6.4 с; тексты на всех трёх устройствах идентичны → `auto`=MPS без fp16.
Первый запуск после установки дольше (компиляция Metal-ядер). На спорных местах сети расходятся
по-разному («Древпром»/«Дрефпром», «00BDR»/«3 нуля БДР») — материал для RU-4.

### FEAT-7 · Файл настроек · P1 · S · ✅
Quick Action не передаёт env-переменные, поэтому из Finder всегда работали умолчания. Теперь `transcribe.sh`
читает `~/Library/Application Support/Transcribe/settings.txt` (КЛЮЧ=значение, только известные ключи, файл не
исполняется как shell). Приоритет: env из командной строки > файл > умолчания. Шаблон со всеми ключами
создаёт установщик (`transcribe.sh --init-settings`) или первый запуск; при переустановке не перезаписывается.
Язык по умолчанию оставлен `auto` (решение из 27fd95e); зафиксировать — `TRANSCRIBE_LANG=ru` в файле.

**Открыто / дальше:**
- Замер WER обеих сетей на своих записях (RU-4).
- Слияние двух расшифровок в одну «лучшую» (LLM-судья) — стык с FEAT-4.
- Импорт silero_vad ставит `torch.set_num_threads(1)` — в раннере возвращаем; при апдейте пакета перепроверить.

## Качество распознавания (русский)

### RU-1 · Зафиксировать язык · P0 · S
Сейчас `-l auto` ([`scripts/transcribe.sh:134`](scripts/transcribe.sh#L134)). Все записи на русском → поставить `-l ru`. Убирает ложные детекты на коротких/шумных фразах, чуть ускоряет старт. Бесплатно.

### RU-2 · Профиль «максимальное качество» · P1 · S
Набор флагов whisper-cli для large-v3:
```
-l ru --beam-size 8 --best-of 8 --entropy-thold 2.4 --max-context 64
```
- `--beam-size/--best-of` — главный прирост точности (поиск вместо жадного);
- `--entropy-thold` — отсекает зацикленный бред;
- `--max-context` — связность терминов/пунктуации на длинной записи.

**НЕ делать:** `--temperature 0.0` — выключает fallback, провоцирует зацикливание; агрессивную ffmpeg-фильтрацию звука (вредит whisper).

**Плата:** beam/best-of 8 ≈ в 2–4× медленнее. Компромисс — `--beam-size 5 --best-of 5`.

**Сделать:** env-переменная `QUALITY=max|balanced|fast`, самообучающийся множитель времени подстроится сам.

### RU-3 · Опциональный VAD · P2 · M
Свежий whisper.cpp умеет `--vad` с моделью Silero (отдельный файл ~десятки МБ) — убирает выдуманный текст в тишине/паузах. Полезно на реальных встречах.

**Сделать:** докачивать VAD-модель в установщике, включать флагом.

### RU-4 · Исследование: альтернативные модели · P3 · M
- **large-v3** — уже одна из лучших для русского (WER ~5–10% на чистом аудио). Базовая рекомендация.
- **Русские файнтюны Whisper** (`bond005/whisper-large-v3-ru` и др.) — надо конвертировать в ggml; выигрыш небольшой и без гарантий.
- **GigaAM (Sber)** — SOTA для русского, другой стек (Python/PyTorch). ✅ Встроен второй сетью — см. FEAT-6.

**Сделать:** мини-эксперимент на реальной записи — large-v3 vs GigaAM (теперь обе расшифровки кладутся рядом автоматически), замер WER (`jiwer`) по выверенному эталону. Без замера на своих данных выбор модели — гадание.
